모리패 Moripae
1. 모리패는?
모리패(Moripae)는 모바일 리듬 게임 패드(Mobile Rhythm Game Pad)를 줄여 만든 이름입니다.

모리패는 안드로이드 기반의 스마트폰과 태블릿 PC를 윈도우 기반 PC와 연결하여, 터치만으로 조작할 수 있는 직관적인 리듬 게임 전용 패드로 변신시켜 주는 애플리케이션입니다.

기존의 키보드 중심 조작 방식에서 벗어나, 터치스크린을 통해 보다 편리하고 직관적으로 게임을 즐길 수 있도록 설계된 새로운 방식의 프로그래밍 기반 조작 시스템입니다.

현재 모리패는 개발 단계에 있으며, 윈도우 PC용 Steam에서 제공되는 《펌프 잇 업 라이즈(Pump It Up RISE)》의 플레이를 지원합니다.

별도의 키보드 조작에 의존하지 않고, 앱 내에서 제공하는 컨트롤러를 통해 게임의 주요 조작을 수행할 수 있도록 개발되고 있습니다.

모리패는 게임 개발사인 안다미로(ANDAMIRO)와 어떠한 제휴·협력·공식적인 관계도 없는 개인 개발 프로젝트입니다.

안다미로에서 제작하거나 공식적으로 승인한 애플리케이션이 아니며, 직관적인 게임 플레이를 목적으로 개인이 독립적으로 개발한 비공식 게임 컨트롤러 애플리케이션입니다.
펌프 잇 업 라이즈의 게임 플레이가 키보드를 기반으로 진행이 되는데 키보드로 누르기에는 키가 작은 감이 있습니다.

적응하면 무리가 없긴 하겠지만 키보드 배열이 대각선 사선 구조라서 펌프 잇 업의 형태의 게임을 플레이하기에는 조작이 애매하다는 생각이 들었습니다.

손펌프콘이라는 형태로 시중에 판매되는 PC용 컨트롤러가 있지만 가격이 15~20만 원 사이에 높은 가격대가 형성되어 있기도 하고 부피가 생각보다 크기도 하고 버튼을 누를 때 소음이 있다는 부분도 있습니다.

안다미로에서도 펌프 잇 업 라이즈 전용 컨트롤러 정식 출시가 예정되어 있지만 아직 정식 출시 전이기도 하고 새로운 형태의 컨트롤러를 만들어 보고 싶어서 AI의 도움을 받아서 모바일 앱 방식으로 제작을 하고 있습니다.

아직은 개발 중인 베타 테스트 단계로 정식 공개된 버전은 없습니다.

모바일 최적화

앱 실행 시 가로 화면 고정, 기본 UI 숨김, 화면 꺼짐 방지 및 직관적이고 편안한 UI 제공.

다중 게임 모드 및 버전 지원

싱글 1P/2P, 하프, 더블 모드 지원 및 각 모드별 4가지 버튼 배열 스타일 제공.

PC 간편 연결

PC 리시버와 QR 코드 인식으로 즉시 연결. 최초 1회 키 설정으로 바로 게임 플레이 가능.

멀티터치 및 터치 진동

동시 누르기, 롱노드 길게 누르기 지원 및 지속적인 터치 진동 피드백 제공.

버튼 및 테마 색상

단색 / 네온 / 믹스 3가지 버튼 색상과 기본 다크 / 아케이드 / 네온 / 라이트 아케이드 4가지 테마 색상을 제공하여 사용자에게 맞는 시각적 효과를 제공.

맞춤 키 설정

5키 / 6키 / 10키 개별 키 설정 및 각 버튼에 커스텀 이미지 등록 가능.

라이즈 전용 키패드

펌프 잇 업 라이즈에 필요한 모든 키를 탑재하여 키보드 없이 모든 조작 가능.

  • • 지원 게임 : 윈도우용 펌프 잇 업 라이즈 스팀 게임 지원 및 윈도우 기반 펌프 잇 업 스타일에 대부분 게임을 지원.
  • • 3종 키 지원 : 5키 / 6키 10키 지원. (각각 개별 키 세팅이 가능.)
  • • 모바일 기기 전용 : 안드로이드 7.0 이상 스마트폰과 태블릿 PC를 지원.
  • • PC 자동 연결 : QR 코드 스캔해서 PC와 연결. (IP 주소가 변하지 않으면 다음번 사용 시 QR 스캔 없이 자동 연결.)
  • • 다양한 모드 지원 : 싱글 1P / 싱글 2P / 하프 / 더블 4가지 모드의 지원 및 4가지 버튼 배열을 지원.
  • • 터치 지원 : 사용자가 버튼 누르는 것을 진동을 통해서 손끝으로 전달. (켜고/끄기 가능하나 무조건 켜는 것을 추천.)
  • • 롱노드 터치 지원 : 버튼을 누르는 순간부터 떼는 순간까지 누르는 것에 대하여 터치 진동을 전달.
  • • 버튼 색상 선택 : 단색 - 버튼 안쪽에 색상 표시 / 네온 - 테두리에만 색상 표시 / 믹스 단색 + 네온 색상 표시
  • • 버튼 테마 지원 : 기본 다크 / 아케이드 / 네온 / 라이트 아케이드 4가지 테마 색상을 지원.
  • • 버튼 이미지 설정 : 사용자가 원하는 이미지를 넣어서 버튼으로 꾸밀 수 있음.
  • • 라이즈 키패드 : 라이즈 게임에 필요한 모든 키를 앱안에서 사용 가능. (키보드 없이 모든 조작 가능.)
  • • 볼륨 조절 : 윈도우 시스템 볼륨을 조절 가능.
  • • 자동 실행 & 종료 : 펌프 잇 업 라이즈 게임을 자동으로 실행하고 종료까지 앱안에서 모두 가능.

모리패 빠른 실행 가이드

  1. PC 호스트 앱 실행: PC에서 모리패 호스트(서버) 프로그램 또는 리시버를 실행합니다.
  2. 와이파이 연결 확인: 모바일 기기와 PC가 동일한 Wi-Fi 네트워크에 연결되어 있는지 확인합니다.
  3. QR 코드 스캔: 모리패 앱을 실행한 후 화면 상단의 'QR 스캔 연결' 버튼을 눌러 PC 화면의 QR 코드를 인식합니다.
  4. 키 설정 및 테스트: 최초 접속 시 키 매핑을 확인하고 버튼을 터치하여 반응 속도와 진동을 테스트합니다.
  5. 게임 플레이 즐기기: 펌프 잇 업 라이즈 및 지원 게임을 실행하여 몰입감 넘치는 터치 플레이를 즐깁니다!
